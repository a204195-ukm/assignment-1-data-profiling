This repository contains a Jupyter notebook that profiles the UCI Adult dataset for missing values, outliers, duplicates, inconsistent labels, and PII or bias risks.

## Run

1. Install Python 3.10 or later and Jupyter Notebook or JupyterLab.
2. Install dependencies: `python -m pip install pandas numpy matplotlib seaborn`.
3. Open `assignment_1_data_profiling.ipynb` and select **Run All**.

The notebook downloads the official dataset from UCI when it runs, so internet access is required. It was tested top to bottom with no cell errors.

Dataset: https://archive.ics.uci.edu/dataset/2/adult
